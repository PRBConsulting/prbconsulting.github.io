# Apps de PRB Consulting

Apps web simples para negocios pequeños, publicadas en GitHub Pages: https://prbconsulting.github.io/

| App | Ruta | Estado |
| --- | --- | --- |
| X3 DATA Lite: compras, ventas, inventario y cierre de caja | `/x3-lite/` | Disponible |
| Finanzas personales: cuentas en $ y Bs, presupuesto y metas | `/finanzas/` | Disponible |
| X3 DATA | `/x3/` | Próximamente |

## Cómo funcionan

- HTML, CSS y JavaScript sin dependencias ni servidor.
- Los datos de cada visitante se guardan solo en su navegador (`localStorage`). Cada app trae datos de ejemplo inventados y permite descargar un respaldo, cargarlo o empezar en blanco.
- Estilos compartidos en `assets/prb.css`.

Todos los datos de ejemplo son inventados.
